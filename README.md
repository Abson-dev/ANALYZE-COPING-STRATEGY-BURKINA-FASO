# How did households in Burkina Faso cope with covariate shocks between 2019 and 2023?

The objective of this analysis is to gain more insight into the coping behavior of households in Burkina Faso when 
facing covariate shocks and stressors of different kinds. To achieve this, we rely on a unique dataset, 
which consists of eleven waves of cross-sectional household data combined with an extensive list of 
shock indicators compiled from external sources.
